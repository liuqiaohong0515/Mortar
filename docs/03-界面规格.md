# 界面规格

对齐 Cornerstone 3 之后的单窗口结构，并保留 4.2 的深色模式。布局用系统控件实现，状态色使用本文规定的值，不复制对方的图标文件。

## 1. 主窗口

最小尺寸 960 × 600。默认 1280 × 800。工具栏与标题栏合一，高度压到系统紧凑工具栏，把垂直空间留给列表。

```
┌──────────────────────────────────────────────────────────────────┐
│ ● ● ●   标题：当前工作副本或仓库名                                │
│ [◀][▶]  [浏览器|比较|日志|时间线|记录]     视图操作…      [检查器] │
├────────────┬───────────────────────────────────────┬─────────────┤
│ 源列表      │ 过滤器条                    [搜索]     │ 检查器      │
│            ├───────────────────────────────────────┤ （可隐藏）   │
│ 仓库 A      │                                       │             │
│   工作副本  │  当前视图                              │  通用       │
│ 仓库 B      │                                       │  状态       │
│   svn://…   │                                       │  属性       │
│            │                                       │             │
│ [+]        │                                       │             │
└────────────┴───────────────────────────────────────┴─────────────┘
```

三栏比例：源列表默认 240pt，可拖到 180–360。检查器默认 300pt，可拖到 260–420。检查器隐藏时主区占满剩余宽度。

没有底栏。Cornerstone 3 去掉了底栏，状态放进源列表、列和检查器。

### 1.1 工具栏

左侧固定：

- 后退、前进。在浏览器中可用；其他视图沿用各自的返回语义（比较视图的 Escape 等价于回到上一视图，同时点亮后退）

中部：

- 视图分段，五项文字：**浏览器**、**比较**、**日志**、**时间线**、**记录**
- 当前上下文不能用的段置灰。例如没选中文件时「比较」置灰；仓库浏览器没有工作副本记录以外的「搁置」

右侧随视图变化，按从左到右的顺序放主要动作，最后一颗永远是检查器开关。

| 视图 | 右侧按钮 |
| --- | --- |
| 工作副本浏览器 | 更新、提交、打开、与 BASE 比较、与 HEAD 比较、忽略项、外部项、仓库状态、检查器 |
| 仓库浏览器 | 检出、导入、标签、分支、下载、刷新、检查器 |
| 比较 | 上一差异、下一差异、外部工具、标注、检查器 |
| 日志 | 显示差异、刷新、检查器 |
| 时间线 | 外部工具比较、检查器 |
| 记录 | 在工作副本中显示、添加笔记、检查器 |
| 提交 | 取消、提交更改。分段控件隐藏，避免提交过程中切走 |
| 合并 | 取消、合并。分段控件隐藏 |

选中冲突文件时，浏览器工具栏在「打开」处改为带菜单的打开按钮，并加入「解决」。

按钮是线框图标加可选文字。窗口窄于 1100pt 时只留图标，工具提示保留完整名称。

### 1.2 视图切换规则

- 选中源列表项，进入该项上次使用的视图；没有记录时进入浏览器
- 从浏览器对文件执行比较，切到比较，Escape 回到浏览器
- 从日志双击文件，切到比较，Escape 回到日志
- 时间线选中两个修订后，比较区出现在时间线下方，不离开时间线
- 更新开始且偏好允许时，切到记录
- 提交和合并是临时模式，完成或取消后回到进入前的视图

## 2. 源列表

使用系统侧边栏材质（浅色半透明，深色对应深色材质）。

```
工作副本
  仓库昵称                         分组，不可选为“当前文件”
    图标  工作副本名          3   12
  另一仓库
    图标  客户端               ●
仓库
  图标  昵称
        host /svn/path
```

- 分组标题使用系统 sidebar 分组样式，全大写、次要色、11pt
- 仓库分组下的工作副本缩进 16pt
- 未提交数用填充胶囊，颜色为「已修改」蓝，数字为白色
- 待更新数用描边胶囊，颜色为「仓库有更新」青，数字为同色
- 两者都有时并排，未提交在左
- 无更改则不占位
- 失效项名称使用次要色，图标加禁止角标
- 进行中的项在名称右侧显示小型不确定进度，不使用持续高速旋转的大指示器
- 行高 36pt（工作副本）/ 44pt（仓库，因为有副标题）
- 选中行使用系统强调色

底部与列表底边留 8pt：「+」是 28pt 圆形按钮。有活动时按钮位置变为进度指示，点击弹出最近三条活动，选择一条即打开对应记录。

拖放：

- 拖到列表空白或分组上，松手加入
- 拖动时列表描边使用强调色
- 不是工作副本也不是仓库：松手后提示，不加入

## 3. 过滤器条

高度 32pt，贴在主区顶部，左右边距 12pt。背景是一层 6pt 圆角的浅灰容器（深色模式下用系统 quaternary fill）。

分段是文字按钮，不是图标：

- 字重 medium，11pt，全大写，字距 +0.4
- 未选中：次要标签色，无底
- 选中：白色（深色模式下 elevated 控件色）胶囊，带 1pt 浅阴影，文字为标签色
- 胶囊内边距水平 10pt、垂直 4pt
- 段与段间距 2pt

工作副本浏览器的段：全部、已更改、已修改、冲突、缺失、未版本控制、已切换、已锁定。打开仓库状态后追加「仓库有更新」。

仓库浏览器在分段左侧加修订字段，宽 140pt，弹出菜单含「最新」、最近输入过的修订号和日期。段：全部、最近修订、今天、本周、本月、已锁定。

日志的段见功能规格，放得下时单行，放不下时横向滚动，不换行。

搜索框在最右，宽 180–220pt，系统搜索框样式。有历史时显示放大镜菜单。

## 4. 浏览器（工作副本与仓库）

AppKit 大纲视图，不用 SwiftUI List。原因：多列、列菜单、成万行滚动、拖放和状态图标需要同一套 Finder 式行为。

### 4.1 列

- 表头 28pt，次要色，11pt
- 行高 22pt，名称列图标 16pt
- 名称列主文字 13pt。次要列 12pt、次要色
- 排序指示只出现在当前排序列
- 名称、状态列不可隐藏；其余列可隐藏、可重排，列宽记入会话
- 斑马纹不使用。选中行用系统选中色

### 4.2 状态徽章

12 × 12pt 圆角矩形，圆角 3pt，白色字母，字重 bold 9pt。

| 状态 | 底色 | 字母 |
| --- | --- | --- |
| 已修改 | #007AFF | M |
| 已添加 | #34C759 | A |
| 已删除 | #8E8E93 | D |
| 冲突 | #FF3B30 | C |
| 缺失 | #FF9500 | ! |
| 未版本控制 | #AF52DE | ? |
| 已忽略 | #C7C7CC | I |
| 外部 | #5AC8FA | X |
| 已切换 | #5856D6 | S |
| 已替换 | #FF2D55 | R |
| 受阻 | #FF9500 | ~ |
| 属性修改（内容正常时） | #007AFF 描边、无填充 | M |

深色模式下填充色保持不变，保证状态色不跟界面灰混在一起。属性徽章在深色背景下描边改用 #0A84FF。

「含有更改」是名称列右侧或独立列中的 6pt 实心圆，颜色 #007AFF，只在折叠文件夹上出现。

锁图标 12pt，线框：本人持有为实心，他人锁定为线框，失效为线框加斜杠。

### 4.3 路径条

过滤器条之下、表头之上，高 28pt。段用文件夹名，分隔符为 chevron。当前段为标签色，祖先段为强调色按钮。点祖先段即把该文件夹设为浏览器根。

### 4.4 空状态

- 工作副本没有任何可见项：说明是过滤结果还是目录为空，并提供「显示全部」
- 仓库尚未加载：进度条加「正在读取修订 N」
- 失效工作副本：图标、路径、按钮「重新定位…」

## 5. 比较视图

```
┌─────────────────────────────────────────────────────────┐
│ [BASE ▾ r120]              [WORKING ▾]        [标注]    │
├────────────────────────────┬────────────────────────────┤
│ 行号 │ 标注 │ 文本          │ 行号 │ 标注 │ 文本         │
│      │      │               │      │      │              │
└────────────────────────────┴────────────────────────────┘
```

- 顶栏两侧各一个修订弹出菜单，中间是「↔」。交换按钮对调两侧
- 左右各占 50%，分割线可拖
- 等宽字体，默认 12pt Menlo，行高 1.35
- 差异行背景：新增侧浅青（浅色 #E5F8EF / 深色 #143028），删除侧浅橙（#FDE8D8 / #3A2416）
- 行内差异再加深一档，并加下划线
- 冲突标记行用冲突红的 12% 透明底
- 滚动条轨道上用 2pt 色块标出差异位置。轨道底部是上一个 / 下一个
- 右侧为 WORKING 时，差异块左缘出现圆形按钮：点按把左侧应用到右侧；按住 Option 点按丢弃该块
- 查找条从顶部滑入（`⌘F`），不推动文本布局发生跳动。匹配项在滚动条上用次要标记标出

图片模式替换文本区，顶栏增加分段：并排、擦除、差异。缩放控件在右下：适应、100%、滑杆。

## 6. 日志视图

每条修订是一张卡片式行，不用表格。

```
r1482   张三   昨天 14:22                         [更新] [分享]
日志消息，最多四行，超出折叠
▶ 更改  4
```

展开后：

```
  添加
    图标  path/File.swift
  修改
    图标  path/Other.swift
```

- 修订号等宽、强调色
- 日期用相对时间，工具提示给绝对时间
- BASE 那一条在修订号后加胶囊「工作副本」
- 比 BASE 更旧的条目显示「还原」
- 变更路径按动作分组，组标题为次要色小标题
- 双击路径进入比较
- 卡片间距 8pt，卡片内边距 12pt
- 日志消息使用偏好中的等宽字体，默认 12pt

过滤结果为空时，空状态写明当前分段，并提供「全部」。

## 7. 时间线视图

```
┌──────────────────────────────────────────────────────┐
│ 轴 ▶   r100   r140   r148   r160   r210              │
│ File.swift  ●────●────────●───────●                  │
│  └ 祖先.swift      ●════╗                            │
│ Other.swift ●───────────●────────────●               │
├──────────────────────────────────────────────────────┤
│ 选中两个修订后，这里是比较视图                           │
└──────────────────────────────────────────────────────┘
```

- 每条路径一行，高 36pt
- 轴在左侧，默认可读修订号；展开后每个刻度纵向排日期
- 符号 10pt：添加用实心圆，分支用菱形，修改用小圆，路径上有变更用空心圆，删除用 ×
- 分支点用一条折线连到展开的祖先行
- 悬停符号显示作者和日志首行
- 选中符号使用强调色描边
- 下方比较区默认高度 45%，可拖

未选文件时，时间线空状态提示从浏览器选择文件或文件夹。

## 8. 记录视图

按时间倒序的运行日志，字体等宽 12pt。

每一条：

```
14:01:08  更新  工作副本「客户端」
  A  path/New.swift
  U  path/Old.swift
  C  path/Conflict.swift
```

- 动作字母颜色与浏览器徽章一致
- 进行中的条目底部有确定进度（已知字节或文件数时）或不确定进度
- 失败条目左侧 3pt 冲突红色条，正文含服务器返回的原文
- 笔记以引用块附在条目下方，次要色
- 工具栏「添加笔记」作用于选中条目

## 9. 提交视图

进入后工具栏分段隐藏。

```
┌────────────────────────────┬───────────────────────────┐
│ 日志消息                    │ ☑ 名称            状态     │
│                            │ ☑ src/A.swift      M      │
│ [最近的日志 ▾]              │   └ 差异区                │
│                            │ ☑ src/B.swift      A      │
│ 提交前脚本 [无 ▾]           │                           │
│ 提交后脚本 [无 ▾]           │                           │
│ ☐ 提交后解除锁              │                           │
└────────────────────────────┴───────────────────────────┘
                              [取消]  [提交更改]
```

- 左 40%，右 60%
- 日志框最小高度 160pt，可随窗口变高
- 变更列表复选框列固定 28pt
- 展开的差异区高度 200pt，使用与比较视图相同的着色，只读
- 主按钮「提交更改」位于右下，是强调色按钮
- 有冲突被勾选时主按钮不可用，按钮下方一行冲突红文字说明原因

## 10. 合并视图

顶部四个策略，做成与过滤器相同的文字分段：同步分支、重新集成、拣选、高级。

其下两栏：

**左：工作副本检查**

- 每条检查是一行：通过用绿色勾，警告用橙色感叹号
- 警告行右侧直接放动作按钮（还原、提交、更新）

**右：选项与预览**

- 同步 / 重新集成：源 URL、修订范围说明
- 拣选：修订表，首列复选框，列有修订、作者、日期、消息首行
- 高级：两个路径字段和两个修订字段
- 「选项」弹出菜单收纳深度、空白、换行、忽略历史、只记录合并信息
- 预览列表与提交视图的变更列表同一组件
- 主按钮「合并更改」。检查有警告时仍可点，点之前再确认一次

## 11. 搁置窗口

独立窗口，宽 640，高 520，非全屏表单。

- 顶部分段：搁置并还原 / 保存检查点
- 搁置架弹出菜单：新建… 与已有名称
- 新建时显示名称字段
- 日志字段可选，高 80pt
- 文件列表占剩余高度
- 主按钮随分段改变标题：「搁置更改」或「保存检查点」

取消搁置是同一尺寸的窗口：三列（搁置架、版本、文件），主按钮「应用搁置的更改」。

## 12. 检查器

右栏滚动视图。段标题：11pt、次要色、全大写、字距 +0.6，不是粗体。字段标签 12pt 次要色，无冒号。值 13pt 标签色，长路径换行，不中间截断。截断只发生在单行且用户把栏拖得很窄时，此时工具提示给全文。

段与段之间 16pt。段标题行右侧有折叠 chevron。

词元（关键字、忽略）使用系统 token 样式：强调色浅底、圆角 10pt、可删除。

属性已修改时，值的左侧出现 12pt 蓝色圆点。悬停整个字段时圆点变成按钮。

「保存更改」贴在属性段底部，仅有未保存编辑时为强调色，否则不可用。

## 13. 表单

添加仓库、检出、标签、分支、更新、切换、重新定位使用系统表单（sheet），宽 480。

- 标题 15pt 常规字重，不用粗体
- 主按钮在右，取消在左
- 高级选项放在披露三角形里，默认折叠。检出的修订 / 格式 / 深度 / 外部引用属于高级选项
- 添加仓库的类型分段放在表单最上方，切换类型时保留已经填写的昵称

证书和 SSH 指纹使用单独的警告表单：展示指纹算法和指纹，按钮为「拒绝」「仅此一次」「始终信任」。

## 14. 偏好窗口

系统偏好窗口，工具栏图标六项：通用、工作副本、安全、位置、通知、用户属性。

表单标签右对齐，控件宽 280pt。忽略列表和自动属性是可增删的表。

## 15. 颜色与文字

界面铬（工具栏、侧边栏、分隔线）只用系统灰。彩色只表示状态或「开着」。

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 强调 / 选中 / 已修改 | 系统强调色，默认 #007AFF | 系统强调色 |
| 已添加 | #34C759 | #30D158 |
| 冲突 / 失败 | #FF3B30 | #FF453A |
| 缺失 / 警告 | #FF9500 | #FF9F0A |
| 未版本控制 | #AF52DE | #BF5AF2 |
| 仓库有更新 | #32ADE6 | #64D2FF |
| 次要文字 | secondaryLabel | secondaryLabel |
| 过滤器容器 | #F2F2F7 | tertiarySystemFill |

字体：

- 界面：系统 SF
- 路径、差异、日志消息、记录：用户选择的等宽字体
- 不使用自定义显示字体

图标：SF Symbols 线框风格，粗细与系统控件一致。状态字母徽章是自绘，不用彩色插画图标。

## 16. 深色模式与无障碍

- 颜色不写死在「只适合浅色」的透明度上。差异底色使用上面的成对色
- 状态不只靠颜色：徽章里始终有字母，时间线符号形状不同，记录行有字母
- 所有工具栏按钮有工具提示和辅助功能标签
- 键盘：源列表、浏览器、日志列表支持方向键和 type-to-select
- 减少透明度打开时，侧边栏改用不透明背景
- 尊重系统「显示滚动条：始终」时，时间线轴和比较视图的宽度计算包含滚动条，避免内容被挡住

## 17. 响应

- 源列表、浏览器、日志在万级条目下滚动不掉帧。状态计算放在后台，主线程只收增量
- 打开「显示仓库状态」时，浏览器先画本地状态，仓库状态列后填
- 比较大文件时先显示已算完的第一屏差异，其余在后台补
- 长操作不锁窗口。可以切换到别的工作副本查看，写操作在同一工作副本上排队

## 18. 与功能规格的对应

界面上每一种 Cornerstone 视图都只对应一处，避免同一命令做出两套 UI：

| 功能规格 | 界面 |
| --- | --- |
| 源列表、待更新 | 第 2 节 |
| 仓库 / 工作副本浏览器 | 第 3–4 节 |
| 比较、图片、标注 | 第 5 节，标注条在文本区内侧 |
| 日志 | 第 6 节 |
| 时间线 | 第 7 节 |
| 记录 | 第 8 节 |
| 提交 | 第 9 节 |
| 合并 | 第 10 节 |
| 搁置 | 第 11 节 |
| 检查器与属性 | 第 12 节 |
| 添加仓库、检出、证书 | 第 13 节 |
| 偏好 | 第 14 节 |
