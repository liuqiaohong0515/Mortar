# Mortar 计划文档

Mortar 是 macOS 上的 Subversion 客户端，功能与界面交互对齐 [Cornerstone 4.2](https://cornerstone.assembla.com/)（2019-12-31，公开资料中的最后版本）。

本目录只描述产品，不包含实现代码。

## 资料来源

规格以 Cornerstone 官方帮助书为主，发布说明和产品页为辅。帮助书入口：

- <https://cornerstone.assembla.com/cornerstone/helpbook/pages/working/index.html>
- <https://cornerstone.assembla.com/blog/>（至 4.2 发布说明）
- <https://cornerstone.assembla.com/>

文档里用三种标记区分把握程度：

- **已确认**：帮助书或 3.x/4.x 发布说明写明了行为。
- **产品惯例**：帮助书描述了功能，但没给出像素级布局；按 Cornerstone 3 之后的单窗口结构补全。
- **实现约定**：官方行为依赖已停运服务或沙盒限制；Mortar 用等价能力补齐，并在文中写明差异。

实现时以 **已确认** 为准。与 **实现约定** 冲突时，保留功能，不照搬已失效的登录或沙盒限制。
