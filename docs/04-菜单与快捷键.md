# 菜单与快捷键

快捷键在菜单里显示，并在全文档只定义一次。标注「已确认」的组合来自 Cornerstone 帮助书；其余按 macOS 惯例分配，实现时不要再改含义。

文本字段拥有焦点时，这些快捷键不拦截文字输入。例外是提交视图里的 `⌘T`：焦点在日志字段中时仍然表示提交，回车只换行。

## 11. 上下文菜单

### 11.1 源列表 · 工作副本

更新到最新修订、更新…、提交…、提交全部更改、还原…、清理、切换…、重新定位…、升级工作副本…、合并…、搁置…、取消搁置…、在 Finder 中显示、在终端中打开、从列表移除。

### 11.2 源列表 · 仓库

在 Finder 中显示（file 仓库）、复制 URL、问题跟踪…、缓存…、从列表移除。

### 11.3 工作副本浏览器

与「工作副本」菜单中对选择有意义的项相同，另加：

- 在全部项中显示（有过滤时）
- 比较子菜单
- 打开方式
- 复制路径、复制仓库 URL

不包含：切换…、导出…。这两项留在源列表或「文件」菜单（Cornerstone 3 已从浏览器菜单移除「切换」和「导出」）。

不包含「显示简介」。检查器替代了单独的简介窗口。

### 11.4 仓库浏览器

检出、导入、下载、导出…、新建文件夹、标签…、分支…、复制、粘贴、重命名、删除、锁定、解锁、打破锁、复制 URL、日志、时间线。

非 HEAD 修订时，重命名、删除、粘贴移动置灰；复制、新建文件夹、导入、下载、导出保持可用。

### 11.5 提交列表

全部勾选、全部取消、勾选已修改、勾选已添加、取消未版本控制项。

### 11.6 记录

显示差异、在工作副本中显示、添加笔记、复制文本。

## 13. 禁用规则

菜单项用隐藏以外的方式处理不可用：保持可见并置灰，让人知道命令存在。

| 条件 | 置灰 |
| --- | --- |
| 未选择工作副本或文件 | 更新、提交、还原、合并、搁置 |
| 选择中没有未提交修改 | 提交的「执行」按钮、搁置 |
| 存在未解决冲突且被勾选 | 提交的「执行」按钮 |
| 单选目录或图片 | 浏览器中的「搁置更改…」 |
| 非冲突项 | 解决、使用工具解决 |
| 浏览历史修订 | 仓库中的重命名、删除、移动 |
| 未选两修订 | 时间线的外部比较 |
| 无搁置架 | 取消搁置的应用按钮 |
| 文件夹 | 内容比较、锁定 |
| 已受版本控制 | 忽略、添加 |
